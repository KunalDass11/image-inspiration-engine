## Portfolio architecture
- Keep the portfolio as a single page with semantic section anchors; navigation follows the sections rather than creating duplicate content pages.
- Keep supplied facts and links in the browser-safe portfolio data module; shared project previews are illustrative components, not claims of deployed product screenshots.
- Use global semantic CSS tokens and the shared Button control for consistent presentation and keyboard interactions.
- Use Lovable asset pointers for supplied photography so the original portrait remains unchanged and is served efficiently.
